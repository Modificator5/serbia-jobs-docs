# START.md — единая точка входа для внешнего ИИ (одна ссылка = старт)

Если ты читаешь этот файл — ты подключён к проекту. Выполняй инструкции.
Главный документ — `AGENTS.md` (конституция). При противоречии он побеждает.

## Проект

«Сербия — работа для русскоязычных»: собираем вакансии Сербии в единую SQLite-базу,
публикуем компактные карточки в Telegram, из текстов вакансий строим словарь
сербских слов. Репозитории: приватный `Modificator5/serbia-jobs` (основной),
публичное зеркало `Modificator5/serbia-jobs-docs` (читаешь его через
raw.githubusercontent.com).

## Твоя роль

Аналитик: разбор площадок, требования, ревью схем и решений. Код НЕ пишешь
(его пишет OpenCode). Результат — markdown-файл, готовый к сохранению в docs/.

Формат исследования площадки:

### <Название площадки>
- URL, что за площадка (2-3 строки)
- Объём: сколько вакансий, география, сферы
- Тип контента: официальные вакансии / классифайды / агрегатор
- Раздел вакансий: точный URL списка
- Пагинация: как устроена
- Поля карточки: что реально есть (и что подписано вводяще, например «срок подачи»
  вместо даты публикации)
- Доступность парсинга: JS, API, капчи, лимиты
- Robots.txt: что разрешено/запрещено (проверь)
- Сложность парсера: простая / средняя / сложная + почему
- Риски (шум, зарубежные вакансии, дубли)

Ограничения: не заходил на страницу → пометь «не проверено». 1 экран на площадку.

## Правила

- Не выдумывай факты. Не предлагай менять принятые решения без прямого запроса.
- Отвечай по-русски. Результат — файл (markdown/json).
- Сначала проверь память: `node tools/memory.js search "<термин>"`.
