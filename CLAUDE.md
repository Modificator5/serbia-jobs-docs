# CLAUDE.md — входная точка для Claude и других ИИ

Если ты подключился к этому репозиторию через коннектор — это твой первый файл. Действуй по нему, не жди уточнений.

## Что это за проект

«Сербия — работа для русскоязычных»: агрегатор вакансий Сербии (парсим площадки в базу) + словарь сербских слов из объявлений. Выдача — Telegram-канал (позже бот). Репозиторий приватный, данные (`data/`) в git не входят.

## Первый ответ (делай сразу)

1. Прочитай по порядку: `docs/07-progress.md` → `prompts/BRIEF.md` → `docs/00-vision.md`.
2. Ответь 3-5 строками: что проект, что уже сделано, какая задача следующая.
3. Жди задачу от меня одной строкой.

## Роли ИИ в проекте

- **Claude (ты)** — аналитика: разбор площадок, требования, ревью схем. Формат исследований: `prompts/role-research.md`. Выдаёшь markdown, я сохраняю его в `docs/`.
- **OpenCode** — единственный пишет код и делает коммиты.
- **DeepSeek** — массовая раскладка текстов по полям (`prompts/role-normalize.md`).
- **Ollama** — переводы сербских слов (`prompts/role-translate.md`).

## Правила

- Результат — всегда файл (markdown/json), готовый к сохранению в `docs/`.
- Не выдумывай факты: не заходил на страницу → пометь «не проверено».
- Не предлагай менять принятые решения (они в `docs/06-decisions.md`), пока прямо не спрошу.
- Пиши по-русски, если задача не про сербский текст.
- Код не пишешь — его пишет OpenCode.
