# Сербия — работа для русскоязычных

Агрегатор вакансий Сербии: парсим открытые площадки в одну базу, показываем компактными карточками (веб-просмотрщик → Telegram-канал) и параллельно строим словарь сербских слов из реальных объявлений.

## Как запускать (все команды из корня репозитория)

| Что | Команда |
|---|---|
| Спарсить Infostud (свежее, 2 стр.) | `npm run scrape:infostud` |
| Спарсить KupujemProdajem (свежее, 5 стр.) | `npm run scrape:kp` |
| Спарсить HaloOglasi (главная /posao) | `npm run scrape:ho` |
| Перевести НОВЫЕ должности (кэш + база) | `npm run translate` |
| Импортировать словарь из базы знаний | `npm run import:glossary` |
| Обновить CSV-снимок | `npm run export:snapshot` |
| Открыть сайт с карточками | `npm run viewer` → http://localhost:7788 |
| ВСЁ разом (ночной ритуал) | `bash tools/daily.sh` |

Полные прогоны (не для каждого запуска!): `npm run scrape:kp -- 20`, `npm run scrape:infostud -- 10`.

## Цикл парсинга: как запускается

**Сейчас (ручной):** ты говоришь мне (OpenCode) задачу → я запускаю нужные парсеры + перевод + снимок. Больше ничего нажимать не нужно.

**Ночью (по расписанию, включается одной строкой):**

```bash
crontab -e   # добавить строку:
30 3 * * * /home/delf/repositories/serbia-jobs/tools/daily.sh
```

`daily.sh` делает за ночь: свежий парс трёх площадок → перевод только новых должностей → CSV-снимок. Лог — `logs/daily-ГГГГ-ММ-ДД.log`. Утром — база свежая, никаких уведомлений днём (это принципиально: ТГ-канал получает выгрузку утром, ты не засоряешь ленту пушами).

## Откуда берутся вакансии и что с ними происходит

```
площадка → парсер (scrapers/*.js) → jobs.db (одна нормализованная схема!)
                                      ↓
                     professions (кэш переводов) → title_ru
                                      ↓
                     viewer/ сайт-карточки  →  (будущее) Telegram-канал
```

Любая площадка приводится к одному виду (docs/03-schema-jobs.md), карточка по шаблону docs/10-telegram-card.md — неважно, откуда пришла вакансия.

## Словарь

`data/glossary.db` — слова/фразы из реальных объявлений + личная база знаний (95 терминов + 30 фраз, verified). Источник: `docs/glossary/bazaznanja.txt`, загрузчик: `npm run import:glossary`. Как использовать — придумаем (слово дня, подсказки в боте).

## Правила

- Секреты только в `.env` (в git не входит).
- `data/` в git не входит — бэкап через `snapshots/jobs.csv`.
- Каждая задача заканчивается коммитом; статусы — в `docs/07-progress.md`.
- Паузы парсеров не уменьшать; полные прогоны — только по явной команде.
