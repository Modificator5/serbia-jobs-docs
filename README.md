# Сербия — работа для русскоязычных

Сервис, который собирает вакансии Сербии из многих площадок, показывает их компактными карточками в Telegram и параллельно строит словарь сербских слов и фраз из реальных объявлений о работе.

## С чего начать

1. Прочитай `docs/00-vision.md` — зачем проект и для кого.
2. Прочитай `docs/07-progress.md` — что уже сделано и что дальше.
3. Задачи — в канбане: `http://localhost:3777` (батчи = фазы).
4. Код — в `scrapers/`, `bot/`, `api/`. Данные — в `data/`.

## Карта репозитория

```
docs/        Вся правда проекта. Каждый ИИ читает отсюда.
prompts/     Промпты-роли для внешних ИИ (Claude, DeepSeek, Ollama).
scrapers/    Парсеры площадок → data/jobs.db
bot/         Telegram-канал → позже бот с подписками
api/         Общий API (для бота и будущего сайта)
data/        jobs.db, glossary.db, временные выгрузки
```

## Роли ИИ

| Кто | Что делает |
|---|---|
| OpenCode | Единственный пишет код в этот репозиторий |
| Claude / ChatGPT | Аналитика: площадки, требования, ревью схем |
| DeepSeek | Массовая раскладка текстов вакансий по полям |
| Ollama (локально) | Перевод сербских слов и фраз |

Правило: любой ИИ заканчивает работой файл в этом репо. Ничего не живёт «в чате».
