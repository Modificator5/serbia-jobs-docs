# 10 — Карточка вакансии: канон и шаблон для Telegram

## Канонические поля (любая площадка → один вид)

| Поле | Откуда | Обязательно | Если нет |
|---|---|---|---|
| title_sr | парсер | да | карточка не создаётся |
| title_ru | кэш professions (tools/translate-titles.js) | стремимся | строка не выводится |
| city | парсер | желательно | строка не выводится |
| salary_raw | парсер (из заголовка/поля) | желательно | строка не выводится |
| snippet | парсер (сниппет листинга) | желательно | строка не выводится |
| company_short | парсер | нет | строка не выводится |
| posted_at | парсер | желательно | строка не выводится |
| source_url | парсер | да | карточка не создаётся |
| category_tag | scrapers/db.js (CATEGORY_MAP) | да | 'drugo' |

Правило: **пустые поля не рисуем** (консенсус бэктеста, 06-decisions). Никаких «н.д.», прочерков и пустых строк.

## Шаблон Telegram-сообщения

```
{title_sr} — {title_ru}
📍 {city} · 💰 {salary_raw} · 📅 {posted_at}
{snippet (до 3 строк)}
{source_url}
#{category_tag}
```

Пример (реальная вакансия из базы):

```
Roštilj majstor — Мастер по грилю
📍 Beograd
Potreban majstor za roštilj sa iskustvom...
https://kupujemprodajem.com/poslovi/...
#zanat
```

Правила вывода:
1. Строки 2 собираются из непустых частей через «·»; если нечего — строка отсутствует.
2. Сниппет — сербский оригинал (перевод сниппетов = отдельный этап, экономия).
3. Хэштег категории всегда (для drugo — без хэштега или #другое).
4. Дата — без времени, вида ДД.ММ.ГГГГ (время публикации для читателя не нужно).
5. Порядок строк фиксирован — так карточки читаются как лента одного канала.

## Что НЕ выводим (и почему)

- счётчики просмотров — шум, ложный стресс конкуренции;
- метка «Plaćena promocija» — выглядит как реклама;
- возраст «pre X dana» — заменён точной датой.

## Этапы, которых пока нет (осознанно, экономия)

- **Полное описание** — только на странице объявления (450+ запросов). План: обогащение ТОЛЬКО выбранных к публикации карточек перед выгрузкой в канал.
- **Требования кандидату** — там же, в полном тексте.
- **Перевод сниппета** — когда решим, как использовать словарь (массово через воркеры, пачками).
