# Замысел

## Проблема

Русскоязычный человек в Сербии ищет работу. Вакансии разбросаны по площадкам (Infostud, KupujemProdajem, Jooble, NSZ...), всё на сербском, описания длинные и местами с мусором. Ни структуры, ни переводов, ни удобной подписки на подходящие варианты.

## Решение

Сервис, который:

1. Собирает вакансии со всех площадок в одну базу.
2. Показывает каждую вакансию компактной карточкой: профессия на сербском + перевод, город, зарплата, 1–2 главных требования, ссылка на оригинал.
3. Публикует карточки в Telegram-канал, позже — бот с подписками по фильтрам (профессия, город).
4. Из текстов вакансий добывает сербские слова и фразы → словарь с переводами для кандидатов.

## Для кого

Русскоязычные люди, которые уже в Сербии или планируют туда переехать и ищут работу: от физработы и hospitality до IT.

## Ценность

- Не надо самому моножить 10 площадок.
- Видно только ключевое — остальное по ссылке.
- Учишь сербский по реальным фразам из объявлений.

## Границы (чего НЕ делаем)

- Не храним полные тексты вакансий в основном каталоге.
- Не заменяем площадки — мы агрегатор и витрина.
- Не берём деньги на старте.
