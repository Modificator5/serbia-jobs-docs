# Журнал решений

Формат: дата, решение, почему, кем принято.

---

## 2026-10-28 — Старт проекта «Сербия: работа для русских»

Принято: собираем агрегатор вакансий Сербии + словарь сербских слов из объявлений.
Почему: существующие площадки не дают структуры и переводов для русскоязычных.

## 2026-10-28 — Один источник правды в репозитории

Решение: весь контекст проекта живёт в docs/, любой ИИ подключается через BRIEF.md.
Почему: распыление по чатам разных ИИ теряет информацию.

## 2026-10-28 — Telegram: сначала канал, бот потом

Решение: MVP — публичный канал с карточками вакансий; бот с подписками — вторым шагом.
Почему: канал проще, быстрее запустить, витрина растёт сама.

## 2026-10-28 — Короткие карточки, сырой текст временный

Решение: в jobs.db только ключевые поля (должность, город, зп, 1-2 требования, ссылка). Полный текст нужен лишь для извлечения слов в глоссарий, затем удаляется.
Почему: не храним большой объём, пост в ТГ должен быть компактным, всё остальное — по ссылке.

## 2026-10-28 — Стартовые площадки

Решение: первыми парсим Infostud, KupujemProdajem (раздел Poslovi), Jooble.
Почему: пользователь назвал их; Infostud и KP подтверждены как рабочие и простые.

## 2026-10-28 — Роли ИИ

Решение: OpenCode — код; Claude/ChatGPT — аналитика; DeepSeek — массовая раскладка; Ollama — переводы.
Почему: у каждого ИИ своя сильная сторона; код пишет только тот, у кого доступ к файлам.
