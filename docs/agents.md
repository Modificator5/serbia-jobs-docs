# ИИ-агенты: инструкции, провайдеры, протокол

Единый инструмент: `./tools/ask.py <провайдер> "промпт"` (ключи — в `.env`,
шаблон `.env.example`). Кеш `.ai_memory/<провайдер>.jsonl` (ключ =
sha256(provider|model|prompt)), fallback по цепочке, журнал `logs/ask-journal.md`
с ротацией в `logs/archive/` при 1 МБ. При повторном запросе — сначала кеш и
журнал, не спрашивать заново.

## Провайдеры

| Команда | Назначение | Модель (по умолчанию) | Статус |
|---|---|---|---|
| `ask.py ollama` | рутина, переводы, батчи | `OLLAMA_MODEL` (gemma4:cloud) | активен |
| `ask.py gemini` | аналитика, архитектура | `GEMINI_MODEL` (gemini-3.5-flash) | активен |
| `ask.py groq` | быстрое ревью кода | `GROQ_MODEL` (llama-3.3-70b-versatile) | активен |
| `ask.py openrouter` | запасной, кросс-проверка | `OPENROUTER_MODEL` (free) | активен |
| `ask.py claude` | аналитика | `CLAUDE_MODEL` (claude-sonnet-4-5) | нужен ключ |

Проверка: `./tools/ask.py <провайдер> "Привет! Ты работаешь? Одна строка JS."`

## Инструкции (файлы)

| Ключ матрицы | Роль | Файл | Формат ответа |
|---|---|---|---|
| — | база для всех | `prompts/worker-core.md` | только результат, без вежливости |
| `LOGIC_CORE` | анализ, архитектура | `prompts/worker-logic.md` | `STATUS: [YES/NO/UNKNOWN]` + `FACTS:` |
| `CODE_FAST` | код, рефакторинг | `prompts/worker-coder.md` | сырой код без fences; ошибка: `ERROR: ...` |
| `ROUTINE_LOCAL` | переводы, батчи | `prompts/worker-routine.md` | конверт `{"status":"success","data":...}` |
| — | оркестратор (OpenCode) | `prompts/lead-engineer.md` | 4 блока: Сравнение/Вердикт/Результат/Действие |

Правило: один запрос = `worker-core` + один ролевой файл. Конверт
`{"status":"success","data":...}` нормализуется в `tools/ai.js`
(`normalizeWorkerJson`); сырой JSON тоже принимается для совместимости.

## Матрица делегирования (жёсткая экономия)

| Ключ | Назначение | Кто |
|---|---|---|
| `ROUTINE_LOCAL` | переводы, батчи, форматирование | Ollama |
| `CODE_FAST` | синтаксис, рефакторинг, ревью | Groq / Llama |
| `LOGIC_CORE` | архитектура, спорные решения | Gemini (+ второй воркер на консенсус) |

Лимиты: ≤2 вызова воркеров на нетривиальную задачу; сырой HTML не отправлять
(только статистика и примеры); Gemini ~10–15 запросов/мин; bulk — короткими пачками.

## Протокол

1. Задача воркеру — только техзадание + Output Format, без вежливости.
2. Формат нарушен → это синтаксическая ошибка: один повтор, затем fallback.
3. Результаты двух воркеров разошлись → третий запрос или ручной аудит.
4. Синтез и решение — за мозгом с доступом к файлам; код пишет только он.
5. Внешний ответ пользователю (оркестратор) — 4 блока: `[Сравнение] [Вердикт]
   [Результат] [Действие]`.
6. Завершённая задача → строка в `memory/tasks.jsonl` + коммит (см. `AGENTS.md` §3).

## Память

- `.ai_memory/*.jsonl` — кеш ответов (автоматически через ask.py).
- `logs/ask-journal.md` — что спрашивали и что ответили (ротация > 1 МБ).
- `memory/tasks.jsonl` — индекс задач с тегами (`tools/memory.js`).
