# ИИ-агенты: провайдеры, матрица, протокол

Единый инструмент: `./tools/ask.py <провайдер> "промпт"` (ключи — в `.env`,
шаблон `.env.example`). Кеш `.ai_memory/<провайдер>.jsonl` (ключ =
sha256(provider|model|prompt)), fallback по цепочке, журнал `logs/ask-journal.md`
(ответы ≤6000 символов). При повторном запросе — опираться на журнал, не спрашивать заново.

## Провайдеры

| Команда | Назначение | Модель (по умолчанию) | Статус |
|---|---|---|---|
| `ask.py ollama` | рутина, переводы, батчи | `OLLAMA_MODEL` (gemma4:cloud) | активен (сервер local) |
| `ask.py gemini` | аналитика, архитектура (LOGIC_CORE) | `GEMINI_MODEL` (gemini-3.5-flash) | активен (.env) |
| `ask.py groq` | быстрое ревью кода (CODE_FAST) | `GROQ_MODEL` (llama-3.3-70b-versatile) | активен, ранее нестабилен |
| `ask.py openrouter` | запасной, кросс-проверка | `OPENROUTER_MODEL` (free) | активен |
| `ask.py claude` | аналитика (заглушка до ключа) | `CLAUDE_MODEL` (claude) | заглушка |

Проверка: `./tools/ask.py <провайдер> "Привет! Ты работаешь? Одна строка JS."`

## Матрица делегирования (жёсткая экономия)

| Ключ | Назначение | Кто |
|---|---|---|
| `ROUTINE_LOCAL` | переводы, батчи, форматирование | Ollama |
| `CODE_FAST` | синтаксис, рефакторинг, ревью | Groq / Llama |
| `LOGIC_CORE` | архитектура, спорные решения | Gemini (+ второй воркер на консенсус) |

Лимиты: ≤2 вызова воркеров на нетривиальную задачу; сырой HTML не отправлять
(только статистика и примеры); Gemini ~10–15 запросов/мин, не пачкать; bulk —
короткими пачками.

## Протокол

1. Все воркеры — «безголовые»: инструкции из `prompts/worker-*.md`, только сырые данные.
2. Результаты двух воркеров разошлись → третий запрос или ручной аудит (не молчать).
3. Синтез и решение — за мозгом с доступом к файлам; код пишет только он.
4. Финальный ответ пользователю: сравнение → вердикт → результат → действие.
5. Завершённая задача → строка в `memory/tasks.jsonl` + коммит (см. `AGENTS.md` §3).

## Память

- `.ai_memory/*.jsonl` — кеш ответов (автоматически через ask.py).
- `logs/ask-journal.md` — что спрашивали и что ответили.
- `memory/tasks.jsonl` — индекс задач с тегами (`tools/memory.js`).
