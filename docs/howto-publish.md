# Инструкция: Как сделать сайт публичным (GitHub Pages)

Если вы хотите, чтобы ваш сайт с вакансиями был доступен всем в интернете по ссылке, выполните эти простые шаги:

## 1. Подготовка (Делаю я)
Я уже создал папку `viewer/public` с двумя файлами:
- `index.html` (сам сайт)
- `jobs.json` (данные о вакансиях)
Эти файлы уже находятся в вашем репозитории на GitHub.

## 2. Активация на GitHub (Делаете вы)
1. Откройте ваш браузер и зайдите в ваш репозиторий на GitHub: `https://github.com/Modificator5/serbia-jobs-docs` (или основной).
2. В верхнем меню нажмите на кнопку **Settings** (Настройки) — иконка шестеренки.
3. В меню слева найдите раздел **Code and automation** и нажмите на **Pages**.
4. В разделе **Build and deployment** $\to$ **Branch**:
   - Выберите ветку `main`.
   - В выпадающем списке папок (рядом с веткой) выберите `/viewer/public` (если такая опция есть) или просто оставьте `/ (root)`. 
   *Примечание: Если GitHub не позволяет выбрать папку `viewer/public`, мне нужно будет переместить содержимое этой папки в корень репозитория или в папку `docs`.*
5. Нажмите кнопку **Save** (Сохранить).

## 3. Результат
Через 1-2 минуты в верхней части этой же страницы (Pages) появится сообщение: 
**"Your site is live at ..."** и ссылка. 

Эта ссылка — ваш публичный сайт. Теперь любой человек может зайти на неё и искать вакансии.
