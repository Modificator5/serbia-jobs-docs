# 08 — Агенты: карта делегирования

Единый инструмент: `tools/ask.py` (ключи — в `.env`). Работает в режиме «жесткой экономии» согласно `docs/delegation-policy.md`.

## Инструментарий
```bash
./tools/ask.py gemini "промпт"        # Google Gemini (аналитика, архитектура)
./tools/ask.py groq "промпт"          # Groq (скорость, синтаксис, ревью кода)
./tools/ask.py ollama "промпт"        # Локально, gemma4:cloud (массовые задачи, переводы)
./tools/ask.py openrouter "промпт"    # Запасной вариант (разные модели)
```

## Статус провайдеров
- [x] **Gemini**: Активен (ключ в .env)
- [x] **Groq**: Активен (ключ в .env)
- [x] **Ollama**: Активен (локальный сервер)
- [x] **OpenRouter**: Активен (ключ в .env)
- [ ] **Claude**: Заглушка (требуется ANTHROPIC_API_KEY)

## Правила работы
1. **Безголовый режим**: Все воркеры используют промпты из `prompts/worker-*.md`.
2. **Синтез**: OpenCode не принимает решение на основе одного ответа воркера.
3. **Логирование**: Каждый вызов фиксируется в `logs/ask-journal.md`.
