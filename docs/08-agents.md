# 08 — Агенты: карта делегирования

Единый инструмент: `tools/ask.py` (ключи — в `.env`, см. `.env.example`).

```bash
./tools/ask.py gemini "промпт"        # бесплатный Google Gemini (аналитика)
./tools/ask.py ollama "промпт"        # локально, gemma4:cloud (массовые задачи)
./tools/ask.py openrouter "промпт"    # запасной free (нужен ключ)
./tools/ask.py claude "промпт"        # заглушка до ANTHROPIC_API_KEY (Phase B)
echo "длинный промпт" | ./tools/ask.py gemini -
```

## Какая задача — кому

| Задача | Воркер | Почему |
|---|---|---|
| Исследование площадок, сводки, аналитика текста | **gemini** | умная, бесплатная, быстрая |
| Массовые переводы, нормализация bulk-данных | **ollama** | локально, без лимитов |
| Всё то же — запасной вариант при 5xx/лимитах | **openrouter** | другой провайдер = второй аптайм |
| Глубокая архитектурная экспертиза | **claude** (Phase B) или ручной релей через `prompts/START.md` | |

## Правила работы

1. Ключей в чат, файлы и git не таскать: только `.env` (в .gitignore).
2. Ответ воркера — черновик. Проверяю факты, ссылки, числа сам, прежде чем сохранить в docs/ или код.
3. 503/429 на Gemini — норма пиковой нагрузки: `ask.py` повторяет сам; если упало — пробую ollama или повторяю через минуту.
4. Лимиты free tier Gemini (~10–15 запросов/мин): подряд больше ~10 тяжёлых запросов не пачкаю, разделяю паузами.
5. Claude вручную: сырой текст задачи → claude.ai → сырой ответ сюда. Через `prompts/START.md`.
