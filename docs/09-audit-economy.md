# 09 — Режим выживания и аудит

## Правила бесплатного режима (выживание)

1. **Парсеры — только свежее.** Дефолты: KP 5 страниц, Infostud 2. Полный прогон — редкое событие по явной команде: `npm run scrape:kp -- 20`.
2. **Паузы между страницами:** KP 800 мс, Infostud 700 мс. Не уменьшать.
3. **ИИ-делегации:** не больше 2 вызовов на задачу (gemini + ollama для бэктеста), промпты компактные (без сырого HTML, только статистика и примеры). Журнал режет ответы до 6000 символов.
4. **Лимиты free tier:** Gemini ~10–15 запросов/мин — не пачкать подряд больше 10 тяжёлых запросов. Ollama (gemma4:cloud) — облачный, тоже ограничен: bulk-задачи короткими пачками.
5. **Тесты без сети:** CSV-снимок `snapshots/jobs.csv` (510 строк) — любой анализ/бэктест можно делать по нему, не трогая площадки и не жгла токены.
6. Переход на платное — когда будет бюджет и подтверждённая польза.
