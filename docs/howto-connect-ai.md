# Как подключить внешние ИИ к этому репозиторию

## Claude (claude.ai, бесплатно)

«Персонализация» в настройках — это НЕ подключение к GitHub. Это просто стиль ответов. Коннектор ставится отдельно:

1. claude.ai → настройки профиля → **Customize → Connectors → GitHub Integration → Connect**.
2. Авторизация на GitHub → выбери репозиторий `Modificator5/serbia-jobs` (приватный — GitHub попросит подтвердить доступ к приложению Claude, подтверди).
3. Проверка: в чате кнопка **«+»** справа внизу → появился пункт **Add from GitHub**.
4. Использование: «+» → Add from GitHub → выбрать репозиторий → в задаче написать: «Прочитай BRIEF.md и docs/07-progress.md, потом ...».

Если пункт «Add from GitHub» не появился — коннектор не подключён, повтори шаги 1-2.

## ChatGPT (бесплатно)

Коннектор GitHub: chatgpt.com/plugins → GitHub → Install → авторизация. На бесплатном тарифе работает нестадильно.

Запасной способ (всегда работает): открыть файл на github.com → кнопка копирования содержимого → вставить в чат вместе с BRIEF.md.

## DeepSeek (бесплатно)

Коннекторов к GitHub нет. Только копипаст: содержимое нужных файлов из репозитория вставляется прямо в чат + задача.

## Ollama (локально)

Ничего подключать не нужно — текст передаётся пачками напрямую в чат модели.

## Важно про приватный репозиторий

- Ссылки `raw.githubusercontent.com/...` на приватный репо не работают без токена — не трать время.
- ZIP-архив (Code → Download ZIP) работает как ручной запасной вариант: скачал, прикрепил к чату.
- Основной путь — коннектор Claude, он читает приватные репозитории после выдачи доступа.
